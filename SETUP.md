# ClubSynk — Setup Guide

## Prerequisites

| Tool | Min version | Install |
|------|-------------|---------|
| Docker Desktop | 4.x | https://www.docker.com/products/docker-desktop |
| Node.js | 18+ | https://nodejs.org (only needed for step 2) |
| pnpm | 8+ | `npm install -g pnpm` |

---

## Step 1 — Unzip and enter the folder

```bash
unzip clubsynk.zip
cd clubsynk
```

---

## Step 2 — Install dependencies and generate shadcn UI components

This must be done on your host machine once, before Docker build.

```bash
pnpm install
pnpx shadcn@latest init --defaults
pnpx shadcn@latest add button input label
```

When `shadcn init` asks questions, use these answers:
- Style: **Default**
- Base color: **Slate**
- CSS variables: **Yes**

> After this runs, the three files `src/components/ui/button.tsx`,
> `input.tsx`, and `label.tsx` will be regenerated by shadcn.
> **Overwrite them** with the versions from this project — they are
> already in `src/components/ui/` and use our ClubSynk theme.
> Just run: `git checkout src/components/ui/` or manually re-copy them
> from the zip after shadcn overwrites them.

---

## Step 3 — Create your .env file

```bash
cp .env.example .env
```

Open `.env` and set **one required value**:

```env
# Generate with: openssl rand -base64 32
BETTER_AUTH_SECRET="paste-your-secret-here"
```

Everything else works as-is for local Docker development.

---

## Step 4 — Create the first Prisma migration

Migrations must exist as files before Docker can run `prisma migrate deploy`.

```bash
# Make sure your .env is set, then run:
pnpm prisma migrate dev --name init --schema=./prisma/schema.prisma
```

This creates `prisma/migrations/` with the initial SQL. You only do this once.

---

## Step 5 — Build and start with Docker

```bash
docker compose up --build
```

Docker will:
1. Build the Next.js app image (~2–3 min first time)
2. Start PostgreSQL and wait for it to be healthy
3. Run `prisma migrate deploy` (applies your migration)
4. Seed the master admin account
5. Start the server on `http://localhost:3000`

You'll know it's ready when you see:
```
clubsynk_app | 🚀 Starting ClubSynk...
clubsynk_app | ✓ Ready on http://0.0.0.0:3000
```

---

## Step 6 — Open the app

```
http://localhost:3000/login
```

| Field    | Default value           |
|----------|-------------------------|
| Email    | `admin@clubsynk.com`    |
| Password | `ChangeMe123!`          |

Change these in `.env` before running if you want different credentials.

## Day-to-day commands

```bash
# Start in background
docker compose up -d

# View logs
docker compose logs -f app

# Stop
docker compose down

# Full reset (wipes database)
docker compose down -v && docker compose up --build

# Connect to the database with a GUI (TablePlus, DBeaver, etc.)
Host: localhost | Port: 5432 | DB: clubsynk | User: clubsynk | Password: clubsynk
```

## Deploying to Vercel

1. Push to GitHub
2. Import repo in Vercel dashboard
3. Add a **Vercel Postgres** database (Storage tab)
4. Vercel auto-populates `DATABASE_URL` and `DATABASE_URL_UNPOOLED`
5. Add your remaining env vars:
   ```
   BETTER_AUTH_SECRET=<your-secret>
   BETTER_AUTH_URL=https://your-app.vercel.app
   NEXT_PUBLIC_APP_URL=https://your-app.vercel.app
   MASTER_ADMIN_EMAIL=admin@yourdomain.com
   MASTER_ADMIN_PASSWORD=<strong-password>
   MASTER_ADMIN_NAME=Master Admin
   ```
6. Deploy
7. Run the seed once from your local machine after deploy:
   ```bash
   DATABASE_URL="<vercel-postgres-url>" \
   DATABASE_URL_UNPOOLED="<vercel-postgres-url>" \
   BETTER_AUTH_SECRET="<your-secret>" \
   BETTER_AUTH_URL="https://your-app.vercel.app" \
     npx tsx prisma/seed.ts
   ```

## Troubleshooting

**Port 3000 already in use**
```bash
lsof -ti:3000 | xargs kill -9
```

**Port 5432 already in use** (local Postgres running)
Edit `docker-compose.yml`: change `"5432:5432"` to `"5433:5432"`.

**Fresh start — wipe everything**
```bash
docker compose down -v
docker compose up --build
```

**Schema changes after initial setup**
```bash
# On host machine
pnpm prisma migrate dev --name your_change_name --schema=./prisma/schema.prisma
# Then rebuild Docker
docker compose up --build
```
